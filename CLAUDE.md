# Project notes

## Writing style
- Do **not** use the words "wild" or "wildly" anywhere (notebooks, markdown,
  comments, commit messages). Prefer alternatives like "dramatically",
  "very", "strikingly".

## Structure
- Course material is organized one folder per day, e.g.
  `Data Cleaning and Exploratory Data Analysis/`, each containing its own
  `data/` and `notebooks/`.
- Notebooks are generated by `notebooks/_build_notebooks.py` within each day
  folder. Edit the generator, then re-run it — do not hand-edit the `.ipynb`
  files directly.
- Markdown cells are wrapped in an inline-styled large-font div (24px) by the
  generator so text is readable in any notebook renderer.
- Each notebook opens with a different pandas reader (read_csv, read_excel,
  read_json, read_parquet, read_feather, read_pickle, read_html); fall back to
  CSV if formats run out.
